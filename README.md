## 🚀 Key Features

- **Architectural Dark Mode UI:** High-contrast tactical design system (`#07080b`, `#d4ff00`, `#38bdf8`) with custom SVG grids and scanlines.
- **Physics-Interpolated Custom Reticle:** Smooth lerp flashlight glow, target aiming dot, and hover-triggered crosshairs.
- **Production Case Studies:**
  - **Khoon:** Emergency blood procurement network with role-gated JWT auth and indexed MongoDB queries.
  - **AtmosAi:** Early-warning air pollution forecasting engine using LightGBM and AWS Bedrock (Claude 3.5 Sonnet).
  - **CodeBridge:** Zero-install ephemeral browser file relay with CSPRNG 6-digit session codes and automatic server shredding.
  - **TwiX:** Developer worklog synthesis & entity-extraction publishing pipeline with FastAPI & OpenAI Responses API.
  - **Legal Demystifier:** Google Cloud GenAI Hackathon prototype simplifying complex contracts into plain-English clauses.
  - **CampusConnect:** Lost & found recovery portal with ownership claim verification workflows.
- **Verified Credentials Showcase:** High-resolution interactive lightbox viewer with direct verification links:
  - *VYUHATECH 2.0 National Hackathon* (CMRIT)
  - *IoTopia 2025 National Hackathon — Top 10 Team* (REVA University)
  - *Gen AI Exchange Hackathon 2025* (Google Cloud × Hack2skill)
  - *Complete 2026 Python Bootcamp* (Udemy)
  - *Python Advanced Training* (Infosys Springboard)
  - *AI Tools & ChatGPT Workshop* (be10x)
  - *Design and Analysis of Algorithms* (Udemy)
  - *Agile Scrum Master* (Simplilearn)
  - *Generative AI Mastermind* (Outskill)
- **Interactive Telemetry:** Live Bengaluru IST clock, recruiter shortcut keys (`R` for resume, `W` for work, `C` for certificates, `S` for skills, `E` for experience), and copyable email badges.

## 💻 Getting Started

### Prerequisites
- Node.js 18.18+ or 20+
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kushal200514/Kushal-portfolio-WebApp.git
   cd Kushal-portfolio-WebApp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
